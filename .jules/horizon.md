## 2024-06-17 — Auth Dependency Modernization
**Risk identified:** The backend authentication was using `passlib[bcrypt]` and `python-jose[cryptography]`. `passlib` is largely unmaintained and throws errors with modern `bcrypt` versions (truncation limitation on hashes due to `bcrypt` handling > 72 bytes natively in modern versions). `python-jose` has seen reduced activity and adds heavy baggage when simple JWT is needed. These dependencies age poorly and cause build issues on modern environments.
**Migration target:** Direct use of modern `bcrypt` package and `PyJWT`. `bcrypt` directly handles hashing correctly, and `PyJWT` is the standard, lightweight, and actively maintained library for JWT handling in Python.
**Migrated this session:** Replaced `passlib[bcrypt]` with `bcrypt` and `python-jose[cryptography]` with `PyJWT` in `backend/requirements.txt`. Updated `backend/core/security.py` to use `bcrypt.hashpw`/`bcrypt.checkpw` and `jwt.encode`/`jwt.decode`. Updated `backend/core/deps.py` to handle `PyJWT`'s `InvalidTokenError`.
**Remaining:** No remaining work for this specific auth migration, it's fully replaced. We should monitor other old dependencies like `aiomysql` vs `asyncmy` or the use of `python-multipart` as the ecosystem shifts.
**Next session:** Investigate the frontend/backend communication primitives for modernization, or evaluate updating major Python frameworks/DB drivers.
